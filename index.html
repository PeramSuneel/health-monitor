Backup and restore

Automatic local snapshot: when you open Health Monitor on a new calendar day, it saves a recovery snapshot in this browser.

This is not an automatic cloud backup and cannot run while the app is closed. Download a JSON backup regularly and keep it somewhere safe. Do not put backup files in this public GitHub repository.

Privacy and data

Your entries are stored in this browser on this device. They are not sent to the GitHub repository. Anyone with access to this browser profile may be able to access them. Avoid entering sensitive health details on a shared or work computer. Clearing browser data may erase records unless you have a backup.

Health Monitor is a personal tracking tool, not a medical device. It does not diagnose, treat or replace professional medical advice. Seek medical help for concerning symptoms or readings.
