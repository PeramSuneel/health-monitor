Import Health Data

Bring Apple Health or Samsung Health history into one private dashboard.

Apple Health

Health app → profile picture → Export All Health Data → Export. Extract the ZIP and select export.xml.

Samsung Health

Samsung Health → Settings → Download personal data. Select the ZIP export. The importer reads supported JSON/CSV files inside it.

Files are processed locally in this browser. Health records stay in this browser and are not uploaded to GitHub. Never commit personal health exports or backups to the public repository.

Supported data (when present in exports)

Steps, calories/energy, distance, exercise, floors, sleep, heart rate, blood oxygen, blood pressure, weight, temperature, glucose and other supported measurements. Samsung export layouts vary by app version; the importer will report files it cannot recognise.

Imports are manual. This website cannot connect live to Apple HealthKit or Samsung Health in the background. Re-importing the same export can create duplicate entries.

Why live automatic collection is unavailable

Apple Health requires HealthKit access in a native iOS app. Samsung Health data access requires supported Samsung integrations and user permissions. A normal GitHub Pages website cannot request those permissions or continuously collect sensor data. This version supports private manual imports from both platforms.

Automatic local snapshot

When Health Monitor is opened on a new calendar day, it saves a local snapshot in this browser (up to 14 daily snapshots). This is not a downloadable file, does not run while the browser is closed, and does not protect against browser data being cleared or device loss. Download a JSON backup regularly and store it in a secure personal location. Never upload personal health records to this public GitHub repository.
