Apple Health Import

Import an Apple Health export file to bring supported measurements into your dashboard.

Import Apple Health export.xml

On iPhone: Health app → profile picture → Export All Health Data → Export. Transfer the ZIP to your computer or phone, extract it, then select export.xml here.

Health exports contain sensitive information. Choose the file locally; it is processed in this browser and is not sent to GitHub by this app.
Supported summaries: steps, active energy, walking/running distance, heart rate, blood oxygen, body mass and sleep duration where the export contains supported records. Import is based on the selected export file; it is not a live or automatic HealthKit connection. Re-importing the same export may create duplicate entries, so review history before importing it again.

Why live automatic collection is unavailable in this website

Apple Health data is protected by iOS HealthKit permissions. A normal HTML website hosted on GitHub Pages cannot request HealthKit access or continuously read Apple Watch measurements. Live collection needs a native iOS app with HealthKit entitlements and user-granted permissions. This web version provides a private, manual export/import workflow instead.

Automatic local snapshot

When Health Monitor is opened on a new calendar day, it saves a local snapshot in this browser (up to 14 daily snapshots). This is not a downloadable file, does not run while the browser is closed, and does not protect against browser data being cleared or device loss. Download a JSON backup regularly and store it in a secure personal location. Never upload personal health records to this public GitHub repository.
